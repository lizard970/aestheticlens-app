\# Codex collaboration rules



\- Never commit directly to `main`.

\- When `HANDOFF.md` exists, treat it as the authoritative task specification.

\- Before editing, read `HANDOFF.md` and inspect only relevant files.

\- Preserve unrelated user changes.

\- Do not add unrequested features or secrets.

\- Run the test commands stated in `HANDOFF.md`.

\- Before finishing, verify the acceptance criteria.

\- Update `HANDOFF.md` with implementation status and test results.

\- Commit and push the completed work to the current branch.

\- In the final response, report changed files, test results, and the commit SHA.
